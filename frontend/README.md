# TrainBench Frontend

React + TypeScript + Vite single-page app for TrainBench. Talks to the FastAPI backend at `/api/v1`.

## Commands

```bash
npm install
npm run dev      # dev server with HMR (port 5173, proxies /api to :8000)
npm run build    # production build -> dist/ (served by FastAPI)
npm run lint     # oxlint
npm run preview  # preview the production build
```

See the root [README](../README.md) for full setup instructions.
